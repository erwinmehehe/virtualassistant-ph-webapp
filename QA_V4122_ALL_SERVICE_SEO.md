# Service SEO Rewrite QA — v4.12.2

## Scope

This pass applies to the complete `/service/[slug]/` library: **74 service pages**. It is not limited to Real Estate.

## What changed

- Every service meta title is now direct, hiring-intent-led, brand-free, and uses **Virtual Assistant** rather than the `VA` abbreviation in the title.
- All titles are 60 characters or fewer in this build.
- Meta descriptions were rewritten to be concise and role-specific; all are 160 characters or fewer.
- Service intros were rewritten around the actual tasks for each role rather than repeating the old `Build the role around...` formula.
- Added a substantive `How the role works in practice` section using each page's actual tasks, tools, and industry operating context.
- Added a practical first-30-days onboarding section tied to the first three responsibilities of each service.
- Existing task, tools, skills, hiring, interview, FAQ, related-service and industry sections remain in place.
- Specialized service names that previously ended in `VA` are expanded to `Virtual Assistant` in H1 and SEO output.

## Content depth

A conservative rendered-copy estimator (excluding live talent cards and related blog excerpts) places the service pages at roughly **1,949–2,089 words**, averaging about **1,977 words**. The live page may vary slightly because candidate cards and guide blocks are data-dependent. No service page falls below the 1,500-word target in the estimator.

## SEO checks

- Service pages: **74**
- Brand name present in meta titles: **0**
- `VA` abbreviation present in meta titles: **0**
- Titles over 60 characters: **0**
- Descriptions over 160 characters: **0**

## Validation note

The extracted handoff package does not include its installed npm dependency tree, so `npm run typecheck` cannot run in this sandbox without reinstalling dependencies. The attempted check fails at missing packages such as Next.js and Supabase before it can validate application code. Run `npm ci && npm run typecheck && npm run build` in the deployment environment.
